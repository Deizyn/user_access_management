1. ภาพรวมและฟังก์ชันหลักสำหรับผู้ใช้งาน (User Guide & Admin Features)
คู่มือความเข้าใจเบื้องต้นสำหรับผู้ใช้งานระบบ ผู้ดูแลระบบ (IT Admin) และฝ่าย HR

ระบบ User Access Management (UAM) Dashboard ถูกออกแบบมาเพื่อให้ผู้ดูแลระบบและองค์กรสามารถตรวจสอบ ค้นหา และบริหารจัดการสิทธิ์การเข้าถึงระบบต่างๆ ของพนักงานได้อย่างถูกต้อง รวดเร็ว และเป็นระบบ โดยรวมสิทธิ์ทั้งหมดไว้ในหน้าเดียว

📊
1. Dashboard Analytics & KPI Summary
แสดงการ์ดสรุปสถิติสำคัญเรียลไทม์ เช่น จำนวนพนักงานทั้งหมด, สัดส่วน Internet Level (Level A / B / C), จำนวนพนักงานที่ได้รับสิทธิ์ VPN, สิทธิ์การพิมพ์งาน (Color / Mono) และสถิติแยกตามบริษัท/แผนก
👥
2. Master User Table & Smart Filter
ตารางผู้ใช้งานหลัก รองรับการค้นหาตามชื่อ/รหัสพนักงาน/ตำแหน่ง/แผนก/บริษัท, ระบบซ่อน/แสดงคอลัมน์ (Column Toggles), การจัดเรียงลำดับ (Sorting) และการแบ่งหน้า (Pagination)
⚡
3. Hybrid Dual-Mode Filtering
รองรับ 2 โหมดการกรอง:
• Dropdown & KPI Card: สลับดูสิทธิ์ทีละกลุ่มใน 1 คลิก (Single-Select)
• Token Popup Bar: เลือกสะสมหลายสิทธิ์พร้อมกัน เช่น ค้นหาบริษัท A + บริษัท B
🔍
4. User Detail Profile Modal
กดดูสิทธิ์เชิงลึกรายบุคคล แสดงการ์ดสิทธิ์ Internet Level, สถานะ VPN, โควตาการพิมพ์งาน, รหัสอุปกรณ์, รหัส PIN โทรศัพท์, ไลเซนส์ Microsoft 365 และการ์ดสิทธิ์พิเศษ (Video, Mail, VoIP ฯลฯ)
📥
5. CSV Bulk Import & Export
รองรับการนำเข้าข้อมูลพนักงานจำนวนมากผ่านไฟล์ CSV (รูปแบบ 14 คอลัมน์มาตรฐาน) พร้อมระบบตรวจสอบความถูกต้องอัตโนมัติ และปุ่มส่งออกรายงานไฟล์ CSV
🏷️
6. Group Explorer & Member Explorer
หน้าต่างสำรวจกลุ่มสิทธิ์ สามารถเปิดดูรายชื่อสิทธิ์ในระบบ และคลิกเข้าไปดูรายชื่อพนักงานที่สังกัดในกลุ่มนั้นๆ ได้ทันที
🔄
2. ขั้นตอนการใช้งานระบบเบื้องต้น (Step-by-Step User Workflow)
แนวทางการปฏิบัติงานสำหรับผู้ใช้งานและผู้ดูแลระบบ
1
ค้นหาและกรองสิทธิ์พนักงาน (Search & Filter)
พิมพ์ชื่อ รหัสพนักงาน หรือเลือกกรองจาก Dropdown Menu (เช่น กรองเฉพาะพนักงานสิทธิ์ Internet Level A หรือสังกัด IT) หรือคลิกการ์ด KPI Summary บน Dashboard เพื่อกรองข้อมูลทันที
2
เรียกดูรายละเอียดสิทธิ์รายบุคคล (View User Profile)
กดปุ่ม "ดูรายละเอียด" บนแถบพนักงาน เพื่อเปิดหน้าต่าง User Detail Modal เรียกดูสิทธิ์ระบบอินเทอร์เน็ต VPN การพิมพ์ รหัสผ่าน และการ์ดสิทธิ์พิเศษประจำตัว
3
การอัปเดตข้อมูลผ่านไฟล์ CSV (Import Bulk Data)
กดปุ่ม "นำเข้า CSV" เพื่ออัปโหลดไฟล์รายชื่อพนักงาน ข้อมูลจะถูกซิงค์และแมปกลุ่มสิทธิ์โดยอัตโนมัติบันทึกลงดิสก์ MySQL ทันที

5. โครงสร้างตารางฐานข้อมูล 3NF (MySQL Clean Schema 2.0)
ตารางสัมพันธ์ 3 ตารางหลัก ในฐานข้อมูล user_access_dashboard_data

1) ตาราง users (Clean 13 Columns Schema)

เก็บเฉพาะข้อมูลโปรไฟล์พนักงาน ปราศจากคอลัมน์สิทธิ์ซ้ำซ้อน

Field Name Data Type Null Key Description
employee_id varchar(50) NO PRIMARY รหัสพนักงานประจำตัว (Unique Key)
username varchar(100) NO UNIQUE ชื่อบัญชี Active Directory
display_name varchar(150) NO - ชื่อ-นามสกุลพนักงาน
email varchar(150) NO - อีเมลประจำตัวพนักงาน
job_title varchar(100) NO - ตำแหน่งงานในองค์กร
department varchar(100) NO - แผนก/สังกัดงาน
company varchar(100) NO - บริษัทในเครือ
device_code varchar(50) NO - รหัสเครื่องคอมพิวเตอร์ประจำตัว
authority_group varchar(100) NO - กลุ่มสิทธิ์การอนุมัติในระบบ
creation_date varchar(50) NO - วันที่เริ่มสร้างบัญชี (YYYY-MM-DD)
expiry_date varchar(50) YES - วันที่หมดอายุสัญญา (ถ้ามี)
telephone_pass_code varchar(50) NO - รหัส PIN โทรศัพท์ / พิมพ์งาน
o365_license varchar(100) NO - สิทธิ์ Microsoft 365 License

2) ตาราง groups (Access Groups Catalog)

เก็บรายละเอียดกลุ่มสิทธิ์และหมวดหมู่ (Category)

Field Name Data Type Description
group_id int (PK) รหัสกลุ่มสิทธิ์ (Master ID 101-109 สิทธิ์พิเศษ, 200+ กลุ่มองค์กร)
group_name varchar(100) UNIQUE ชื่อกลุ่มสิทธิ์ (เช่น Internet Level A, VPN Access, IT Department)
description text คำอธิบายรายละเอียดสิทธิ์
is_special tinyint(1) 1 = สิทธิ์พิเศษ/Master Group, 0 = กลุ่มองค์กรทั่วไป
category varchar(50) หมวดหมู่สิทธิ์: INTERNET_LEVEL, RESOURCE_ENTITLEMENT, NETWORK_VPN, PRINT_QUOTA, ORGANIZATIONAL
badge_color varchar(100) คลาส Tailwind สีป้าย Badge บน UI

3) ตาราง user_groups (Junction Junction Map Table)

เชื่อมโยงความสัมพันธ์ M:N ระหว่างพนักงานและกลุ่มสิทธิ์

Field Name Data Type Constraint
employee_id varchar(50) FOREIGN KEY -> users(employee_id) ON DELETE CASCADE
group_id int FOREIGN KEY -> groups(group_id) ON DELETE CASCADE

6. REST API Endpoints Specification
อินเทอร์เฟซการสื่อสารระหว่าง Frontend และ Backend Express (server.ts)
Method Endpoint Query / Payload Description
GET /api/users - ดึงข้อมูลพนักงานทั้งหมด พร้อม JOIN ข้อมูล user_groups
GET /api/groups ?is_special=true ดึงข้อมูลกลุ่มสิทธิ์ทั้งหมด พร้อมป้ายกำกับ Category
GET /api/user-groups - ดึงข้อมูลจับคู่ความสัมพันธ์ employee_id ➔ group_id
POST /api/db/sync { users, groups, userGroups } บันทึก/อัปเดตข้อมูลแบบ Atomic Upsert ลงดิสก์ MySQL Server
POST /api/db/reset - ล้างข้อมูลพนักงานทั้งหมดใน MySQL (คงไว้เฉพาะ Master Groups 101-109)
POST /api/groups { group_name, category, ... } สร้างกลุ่มสิทธิ์ใหม่ลงในตาราง groups

คำสั่ง SQL Cheat Sheet สำหรับ MySQL Workbench

-- 1. เรียกดูพนักงานพร้อมสิทธิ์ที่สังกัดทั้งหมด (JOIN 3 Tables) USE user_access_dashboard_data; SELECT u.employee_id, u.display_name, u.company, u.department, g.group_name, g.category FROM users u JOIN user_groups ug ON u.employee_id = ug.employee_id JOIN `groups` g ON ug.group_id = g.group_id ORDER BY u.employee_id; -- 2. ตรวจสอบจำนวนพนักงานและกลุ่มสิทธิ์ SELECT COUNT(*) AS total_users FROM users; SELECT COUNT(*) AS total_groups FROM `groups`; SELECT COUNT(*) AS total_mappings FROM user_groups;
